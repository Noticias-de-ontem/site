# Código de Conduta

## O nosso compromisso

Para criar um ambiente aberto e acolhedor, nós — contribuidores e mantenedores — comprometemo-nos a fazer da participação neste projeto uma experiência livre de assédio para todos, independentemente de idade, dimensão corporal, deficiência, etnia, identidade e expressão de género, nível de experiência, nacionalidade, aparência pessoal, raça, religião ou identidade e orientação sexual.

## Comportamentos esperados

- Usar linguagem acolhedora e inclusiva;
- Respeitar pontos de vista e experiências diferentes;
- Aceitar crítica construtiva com gracefully e responder da mesma forma;
- Focar o que é melhor para o projeto e para a comunidade;
- Ser especialmente cuidadoso com temas históricos sensíveis: o projeto lida com períodos como a ditadura portuguesa e exige precisão factual e empatia.

## Comportamentos inaceitáveis

- Linguagem ou imagens sexualizadas, insultos, ataques pessoais ou políticos provocadores;
- Assédio público ou privado;
- Publicar informação privada de terceiros (endereço, e-mail, etc.) sem consentimento;
- Conduta que razoavelmente se considere inadequada num ambiente profissional.

## Aplicação

Casos de comportamento abusivo podem ser reportados ao responsável do projeto através do GitHub ([abrir issue privada ao maintainer](../../issues) ou os contactos no perfil da organização). Todos os relatos serão revistos e respondidos, mantendo-se a confidencialidade.

Os mantenedores que não seguirem este Código de Conduta podem ser removidos temporária ou permanentemente do projeto.

## Atribuição

Este Código de Conduta é adaptado do [Contributor Covenant](https://www.contributor-covenant.org), versão 2.1.
